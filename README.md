# homebrew-tap

Homebrew formula and Scoop manifest for [lcovmerge](https://github.com/megasoft1978/lcovmerge).
The files are updated by pull requests from the lcovmerge release workflow.

## Homebrew (macOS)

```sh
brew tap megasoft1978/tap
brew install lcovmerge
```

## Scoop (Windows)

```sh
scoop bucket add lcovmerge https://github.com/megasoft1978/homebrew-tap
scoop install lcovmerge
```
